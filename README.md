# Minimal Academic GitHub Pages Homepage

This folder contains a one-file academic homepage suitable for GitHub Pages
and OpenReview profile verification.

## 1. Edit `index.html`

Replace:

- `YOUR NAME`
- `YOUR UNIVERSITY / LABORATORY`
- `YOUR_EMAIL@example.edu`

with your real information.

For OpenReview, make sure your public page visibly contains your **name and email**.

## 2. Create a GitHub Pages repository

If your GitHub username is `exampleuser`, create a public repository named:

`exampleuser.github.io`

The repository name must exactly match:

`<your-github-username>.github.io`

## 3. Upload `index.html`

Upload `index.html` to the root directory of the repository and commit it to `main`.

## 4. Enable GitHub Pages

Go to:

Settings -> Pages

Choose:

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

Save the settings.

After deployment, the page will normally be available at:

`https://<your-github-username>.github.io/`

## 5. Use it in OpenReview

Put that URL into **Homepage URL**.

Before submitting OpenReview registration, open the page in a private/incognito browser
window and confirm that your name and email are publicly visible.
